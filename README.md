# DUNGEON: DESCENT

**Pixel Art Dungeon Crawler + Turn-Based JRPG + Roguelite**  
Telegram Mini App ready · Mobile-first · Phaser 3 + TypeScript + Vite

## Quick Start

```bash
npm install
npm run dev
```

## Implemented MVP Systems

- Main Menu + Continue run
- GameState + Save / Load (versioned)
- Meta progression (Soul Shards)
- Room-based dungeon generation
- Turn-based combat with SPEED timeline
- Player skills, Enemy AI, Status effects, Break system
- Loot (rarity, affixes, pity, boss loot)
- Equipment + Inventory
- Level up, Rest, Treasure, Shop, Events
- Boss fights
- Telegram integration layer

See full README after clone for architecture details.
